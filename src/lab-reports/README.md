# Lab reports

Drop a PDF in this folder, push, and it shows up on the site. No code changes.

## Where to put the file

- A report about **one product** goes in a folder named after that product (list below).
  It appears on the Lab reports page and on that product's page.
- A report that covers **everything** goes straight in this folder.

Create the product folder if it doesn't exist yet.

## How to name the file

`YYYY-MM-DD_what-the-report-is.pdf`

The date is optional. Dashes and underscores become spaces on the site.

| File | Shown as |
| --- | --- |
| `2026-09-30_heavy-metals-test.pdf` | Heavy metals test, September 30, 2026 |
| `material-safety.pdf` | Material safety |
